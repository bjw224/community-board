# 커뮤니티 모아보기 — 크롬 확장프로그램

클리앙·뽐뿌·다모앙 게시판을 **실시간(30초~1분)** 으로 확인하고, **본문·댓글까지 한 화면**에서 읽는 PC 크롬용 확장.
요청은 내 브라우저에서 바로 나가므로 서버가 필요 없고, GitHub 서버에서 막혔던 게시판(뽐뿌 HOT, 다모앙 굴러간당·애플모앙)도 볼 수 있음.

## 설치 (1회)

1. 이 `extension` 폴더를 PC의 지울 일 없는 위치에 둠 (예: `문서\community-board-extension`)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 1번 폴더 선택
5. 툴바 퍼즐 아이콘 → **커뮤니티 모아보기** 고정(핀) → 아이콘 클릭하면 열림

> 폴더를 지우거나 옮기면 확장이 사라지니 그대로 두세요. 코드를 고친 뒤에는 `chrome://extensions`에서 새로고침(↻) 버튼.

## 사용법

| 키 | 동작 |
|---|---|
| `j` / `k` | 다음 / 이전 글 열기 |
| `o` | 지금 글 원문 새 탭 |
| `r` | 지금 게시판 새로고침 |
| `/` | 제목 검색 |
| `Esc` | 본문 닫기 |

- 보고 있는 게시판: 클리앙·뽐뿌 30초, 다모앙 60초마다 자동 확인 (탭이 뒤에 있으면 3배 느리게)
- 다른 게시판: 3~6분마다 돌아가며 확인해서 왼쪽에 **새 글 수** 표시
- 새로 들어온 글은 빨간 점 + 노란 배경, 읽은 글은 회색
- 목록에서 Ctrl+클릭하면 원문을 새 탭으로

## 참고

- 뽐뿌 댓글은 페이지가 뜬 뒤 따로 불러오는 방식이라 본문만 표시 (댓글은 원문 열기)
- 다모앙은 요청 수 제한이 있어 20초 간격 이상으로만 요청하고, 429를 받으면 2분 쉼
- 게시판 추가/삭제: `sources.js`의 `BOARDS`
- 이미지가 막히면 "이미지 원본 보기" 링크로 대체
